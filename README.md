# Dynamic Reading Jurnal (APK)

Folder: `www` (aplikasi web), `assets` (ikon), `scripts` (setup Android), `.github` (build otomatis).

## Cara mendapatkan APK
1. Upload seluruh isi folder ini ke repository GitHub (branch `main`).
2. Buka tab **Actions** > workflow **Build Android APK** (jalan otomatis, sekitar 5-10 menit).
3. Setelah hijau, buka run terbaru > bagian **Artifacts** > unduh `DynamicReadingJurnal-apk`.
4. Ekstrak zip, kirim `app-debug.apk` ke HP, lalu pasang (izinkan "instal dari sumber tidak dikenal").
